# NESAM visual assets

This archive contains the visual collection for the customer, driver and vendor web panels, based on the supplied red-and-black NESAM logo.

## Collection

- 106 genuine SVG icons: 65 shared, 11 customer, 17 driver, 13 vendor.
- 106 transparent PNG icon previews at 96 × 96.
- 54 generated illustrations: 18 per panel.
- 8 generated vehicle category cutouts.
- 10 generated travel photographs.
- 3 generated authentication hero illustrations.
- 12 generated symbolic stickers.
- 5 authored SVG decorative backgrounds with PNG versions.
- Original uploaded logo, unchanged, with its original white background.
- Contact sheets, brand style guide, CSV/JSON asset manifest and original brief.

Open `previews/` to browse the collection. Use the individual files rather than cropping the contact sheets. Icons support `currentColor`. Raster sizes vary according to the image-generation tool; exact dimensions and verified alpha transparency are in `asset-manifest/manifest.csv`.

## Intended use

Use illustrations as decorative companions to actual labels and states. Do not imply approval, settlement or verification from imagery alone. Generated photos depict illustrative people and locations. Vehicle cutouts represent categories, not actual assigned cars. Exact logo placement should use the original logo file separately.

Image assets were produced using the built-in image-generation tool. SVG icons and backgrounds were authored as real vector paths; they are not raster traces. The visual direction is red, charcoal and ivory, with restrained semantic green and amber. Generated illustration rendering varies modestly between assets; contact sheets make those variations visible.

## Verification and limitations

All 74 illustration, vehicle and sticker PNGs were checked for alpha transparency. All files are decoded during manifest/contact-sheet generation and the ZIP is tested for integrity. Generated artwork was reviewed in contact sheets and selected images were regenerated to correct subject and style mismatches. This is an asset package; the files have not been integrated into the apps or tested within their pages. Use the original files as supplied: some vehicle images include a subtle ground shadow. Separate shadow-free variants are not included. The imagery preserves the generator's native dimensions rather than promising the approximate target resolutions in the brief.

No required base asset categories remain outstanding. Optional filled icon variants, separate vehicle shadow variants, and a production accessibility review within the actual apps are not included.
